---
title: "Configure mcpjungle's database"
description: "Configure the required MySQL 8.0 database connection for Mcpjungle."
---

Mcpjungle requires MySQL 8.0 to persist registered servers, permission groups, user identities, device tokens, and call records.

## Requirements

Prepare the database before starting Mcpjungle:

- Run MySQL 8.0 or a compatible managed MySQL 8.0 service.
- Use the `utf8mb4` character set for the database and tables.
- Set the database and Mcpjungle runtime time zone to UTC.
- Create a dedicated database and application user with permissions to create and update the schema.
- Make the database reachable from every Mcpjungle instance.

Example database initialization:

```sql
CREATE DATABASE db
  CHARACTER SET utf8mb4
  COLLATE utf8mb4_0900_ai_ci;

CREATE USER 'user'@'%' IDENTIFIED BY 'pass';
GRANT ALL PRIVILEGES ON db.* TO 'user'@'%';
```

<Note>
  Replace the example username, password, host, and database name before deployment. Store production credentials in your secret-management system.
</Note>

## Required connection variable

`DATABASE_URL` is required. It must contain a complete MySQL connection URL:

```bash
export DATABASE_URL=mysql://user:pass@host:3306/db
mcpjungle start
```

For Docker:

```bash
docker run -d \
  --name mcpjungle-server \
  -e DATABASE_URL=mysql://user:pass@host:3306/db \
  -p 8080:8080 \
  ghcr.io/mcpjungle/mcpjungle:latest
```

Mcpjungle validates `DATABASE_URL` at startup and stops immediately when the variable is missing, malformed, or does not use the MySQL scheme.

## Time zone and character set

Keep storage and application timestamps in UTC. Configure the MySQL server with `default_time_zone = '+00:00'`, or use the equivalent setting provided by your managed database service.

The database must use `utf8mb4`. Existing databases can be checked with:

```sql
SELECT @@version, @@global.time_zone, @@session.time_zone;
SELECT DEFAULT_CHARACTER_SET_NAME, DEFAULT_COLLATION_NAME
FROM information_schema.SCHEMATA
WHERE SCHEMA_NAME = 'db';
```

## Production recommendations

<Tip>
  Use a dedicated managed MySQL 8.0 instance and inject `DATABASE_URL` through your deployment secret store. Enable automated backups, point-in-time recovery, TLS, and connection monitoring.
</Tip>

The provided Compose files run MySQL 8.0 with UTC and `utf8mb4` defaults for local and self-contained deployments. For production, use an independently operated database and update `DATABASE_URL` to its private endpoint.
